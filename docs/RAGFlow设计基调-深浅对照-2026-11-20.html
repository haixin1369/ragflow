样式说明

1
暗色优先：与现网一致默认深色，浅色主题作为可切换项保留，两套共用同一组变量。
2
单强调色纪律：靛蓝只给「可点击的下一步」；状态一律用语义色（成功 / 运行 / 失败 / 排队）。
3
描边分层：面板之间用 1px 描边区分层级，不用重阴影；弹层与抽屉才允许投影。
4
数字字体等宽：分块数 / 大小 / Token 等数字列使用等宽数字，便于纵向对齐。
5
中文排版：全局思源黑体（Noto Sans SC，SIL OFL 1.1 开源授权，免费商用）；中西文混排自动间距；表格名称列允许两行截断。
