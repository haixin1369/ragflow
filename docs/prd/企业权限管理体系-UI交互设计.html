交互说明

  • 按人员搜索：可检索全量用户（含跨部门/跨子公司），已授权用户置灰防重复；添加前选择授予层级。

  • 保存后即时生效；被移除成员的下一次请求即被拒绝（技术方案假设 A2）。

  • 删除阻断：名下有知识库时删除被拒绝，错误信息直接点名待转移的知识库，引导跳转「知识库管理」按所有者筛选后强制转移（技术方案 4.2）。
